# 11. 后训练、在线学习与鲁棒闭环

本分块解决的核心问题是：**模仿学习训出来的 VLA 只能达到演示数据的水平，且遇到分布外情况会静默失败；如何让它在部署后继续变强、在失败时能察觉并恢复。** 四条主线：（a）**RL post-training**——用稀疏成功信号做策略优化（RIPT-VLA、SimpleVLA-RL、ConRFT、π*0.6）；（b）**不确定性与求助**——让策略知道自己不知道，触发人类介入（KnowNo）；（c）**失败检测与在线纠正**——运行时判断"是否偏离"并回退；（d）**鲁棒性评测**——把扰动维度显式化（LIBERO-Plus）。

一个关键的经验事实：**RL post-training 的收益极大但高度依赖可靠的成功判定**。在仿真中（成功可自动判定）SimpleVLA-RL 等方法能把 OpenVLA-OFT 从 17.3 提到 91.7；但在真机上，"成功了没有"本身就是一个未解决的感知问题，这是 RL 上真机的最大障碍——ConRFT 等工作因此转向人在回路的干预式学习。

未解决的瓶颈：（1）**真机上的自动成功判定**（reward model）不可靠；（2）**RL 会破坏语言泛化**——在少数任务上 RL 微调后，模型对新指令的遵循度下降，缺乏系统研究；（3）**失败检测几乎空白**——绝大多数 VLA 不知道自己失败了，会一直重复错误动作；（4）**校准的置信度缺失**——策略输出的动作没有可用的不确定度，无法作为"是否求助"的依据（KnowNo 只在离散技能选择层面解决了这个问题，动作层面仍空白）。

**技术演进链：**

`KnowNo（用 conformal prediction 给出有统计保证的"何时求助"）→ ConRFT（真机上的一致性策略 RL 微调 + 人在回路干预）→ RIPT-VLA（只用二元成功信号的交互式后训练）→ SimpleVLA-RL（大规模仿真 RL，用一条演示冷启动即可超越充分 SFT）→ π*0.6 / RECAP（用自身经验 + 优势条件做工业级 RL 后训练）→ LIBERO-Plus（把鲁棒性拆成 7 类扰动，给出可诊断的评测）`

- **KnowNo → ConRFT**：从"检测不确定并求助"推进到"**利用人类的介入数据继续学习**"，把人类干预从代价变成资源。
- **ConRFT → RIPT-VLA**：去掉对稠密奖励与价值网络的依赖，只用**二元成功/失败**，通过动态 rollout 采样 + leave-one-out 优势估计做稳定优化，使 RL 后训练可在任何有成功判定的环境中即插即用。
- **RIPT-VLA → SimpleVLA-RL**：把规模拉满——在 veRL 基础上做 VLA 专用的并行采样与多环境渲染，证明**RL 可以在只有 1 条演示冷启动的情况下超过用完整演示做 SFT 的模型**，并观察到"pushcut"式的新行为涌现。
- **SimpleVLA-RL → π*0.6（RECAP）**：把 RL 后训练带到**真实机器人的生产任务**（制作咖啡、组装盒子、叠衣服），用优势条件训练 + 自身经验 + 人工纠正混合，报告吞吐与成功率的显著提升。
- **（横向）LIBERO-Plus**：与上述纵向路线正交——回答"我们到底在对什么鲁棒"，把扰动拆成物体布局、相机视角、初始状态、语言指令、光照、背景纹理、传感器噪声七类。

## 阅读这一分块时的三个检查点

1. **成功判定从哪来？** 仿真中来自环境（可靠），真机中来自人工/额外模型（不可靠）。这决定了方法能否上真机。
2. **base policy 是什么、起点多低？** 很多惊人的相对提升源于极低的起点（1 条演示冷启动）。
3. **是否评估了"RL 后的泛化退化"？** 绝大多数论文没有报告 RL 后模型在**新指令/新物体**上的表现，这是当前最系统性的评测缺失。
