# 4. 跨本体学习与泛化（cross-embodiment）

本分块解决的核心问题是：**不同机器人的动作空间、观测配置、控制频率、自由度都不同，如何把它们的数据合并训练出一个策略，并让能力在本体之间迁移。** 主流路线有四条：（a）**填充/掩码统一动作空间**（把所有本体的动作 padding 到最大维度，Octo、RDT-1B）；（b）**per-embodiment 编解码头**（共享主干 + 本体专属输入输出头，CrossFormer、HPT、GR00T N1）；（c）**本体条件的软提示 / embedding**（用可学习 embedding 显式表征本体，X-VLA）；（d）**latent action 中间层**（先在与本体无关的 latent 动作空间学习，再各自解码，LAPA、UniVLA）。

已被确认的经验事实：**跨本体联合训练几乎总是带来正迁移**（RT-X、Octo 的核心结论），但**迁移强度与本体相似度高度相关**，且**负迁移在动作分布差异极大时确实存在**（如轮式底盘 vs 灵巧手）。

未解决的瓶颈：（1）**没有本体相似度的定量度量**，数据配比全靠经验调；（2）**morphology 层面的真正迁移**（从单臂学到的技能直接用在人形上）证据仍很弱，多数"跨本体"其实是"跨机型的同类夹爪"；（3）**评测协议缺失**：几乎没有公开的、多机构共享的 cross-embodiment 真机评测集。

**技术演进链：**

`Octo（统一动作空间 + diffusion 头）→ CrossFormer（跨操作/导航/运动/飞行的单一策略）→ HPT（异构本体的统一 tokenization 与可扩展预训练）→ RDT-1B（双臂异构动作空间 + DiT）→ UniVLA（任务中心 latent action）→ X-VLA（软提示式本体表征）`

- **Octo → CrossFormer**：从"同为桌面机械臂的多机型"扩展到"**动作空间语义完全不同的四类本体**（操作/导航/四足/无人机）"，并去掉了对动作空间对齐的假设，改用 per-embodiment 动作头。
- **CrossFormer → HPT**：把重点从"策略"转到"**表示预训练**"——用 stem（本体专属）+ trunk（共享）+ head（任务专属）结构，证明共享主干随数据/参数量呈现可预测的 scaling 行为。
- **HPT → RDT-1B**：面向**双臂灵巧操作**，提出统一到 128 维的物理可解释动作空间（把不同机器人的关节/末端量填到固定语义槽位），用 1.2B DiT 建模多模态动作分布。
- **RDT-1B → UniVLA**：不再对齐"真实动作"，而是从视频中学出**任务中心的 latent action**（用语言过滤掉与任务无关的相机运动/背景变化），使人类视频也能进入跨本体预训练。
- **UniVLA → X-VLA**：回到显式建模，用**可学习的 soft prompt 表征每个本体/数据源**，让同一个主干在被提示后"扮演"不同本体，在多个仿真与真机平台上刷新结果。

## 四种本体对齐方案对照

| 方案 | 代表工作 | 归纳偏置 | 新本体接入成本 | 主要风险 |
|---|---|---|---|---|
| Padding + mask 统一动作空间 | Octo | 动作维度可对齐 | 低（改 mask） | 维度语义不一致导致干扰 |
| 物理语义槽位统一空间 | RDT-1B | 动作有共同物理含义 | 中（需定义槽位映射） | 新形态需重设计槽位 |
| per-embodiment 编解码头 | CrossFormer, HPT, GR00T N1 | 主干可共享、接口可分离 | 中（训练新 stem/head） | 头部数据少时欠拟合 |
| 软提示 / latent 中间层 | X-VLA, LAPA, UniVLA | 本体差异可被低维变量捕获 | 低（学一组 embedding/解码器） | 可解释性差、零样本新本体存疑 |
